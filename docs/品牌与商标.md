## 主色板

对外材料（网站、PPT、宣传图）统一使用这套暖棕色系，不要引入蓝色等外来色。

| 色值 | 用途 |
|---|---|
| `#2E2822` | 主标题、正文重点 |
| `#4A3729` | 深棕，卡片标题、强调块 |
| `#C79255` | 品牌金棕，重点数字、行内强调、装饰短线 |
| `#E0B77F` | 浅金棕，时间轴当前节点 |
| `#7D746C` | 正文灰 |
| `#B8AEA5` | 注释、脚注 |
| `#E8D7C2` / `#F5EEE5` / `#FAF6F0` | 卡片与提示条底色 |
| `#72866F` / `#A85E4A` | 辅助绿 / 辅助红，仅用于正负指标 |
