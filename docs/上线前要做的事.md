## 3. DeepSeek Key 放哪

**放后端，不放小程序。**

- 本地：Pawly 仓库根目录 `.env.local`
  ```
  DEEPSEEK_API_KEY=sk-xxxxxx
  PAWLY_MODEL=deepseek-v4-pro
  DEEPSEEK_BASE_URL=https://api.deepseek.com/chat/completions
  ```
- 线上（Vercel）：Settings → Environment Variables，Production 环境加同样三个，
  加完要 **redeploy** 一次才生效
- 自有服务器：见 Pawly 仓库 `docs/部署-自有服务器.md`

顺带确认一下 `https://www.aipawly.com/api/chat/diagnose` 能返回连通性结果 ——
这个接口只回错误分型，不回显 Key，可以安全地拿来自查。

小程序端只调 `/api/chat`，Key 全程不出后端。**小程序包会被反编译，任何写进前端的密钥都等于公开。**

## 4. 流式对话

`config.js` 的 `useChatStream: true` 会走 `/api/chat/stream`（SSE），依赖
`wx.request` 的 `enableChunked`，需要**基础库 ≥ 2.20.2**。
拿不到分片会自动回落到非流式的 `/api/chat`，不会白屏。

如果后端挂在 Nginx 后面，记得关掉反代缓冲，否则流式会退化成"一次性吐出来"：

```nginx
proxy_buffering off;
proxy_cache off;
chunked_transfer_encoding on;
```

（Pawly 的 `/api/chat/stream` 已经带了 `x-accel-buffering: no`，但 Nginx 侧也确认一下更保险。）

## 6. 素材

小程序**不需要**任何图片素材：商品图、文章配图、社区封面全部沿用网页端的
「色块 + emoji」方案（`data/products.js` 里的 `bg` + `emoji` 字段），
和网页端在没有真实图片时的表现完全一致。

如果之后网页端补了真实商品图（`public/images/products/<id>.jpg`），小程序这边
在 `components/product-card/index.wxml` 的 `.art-box` 里加一个 `<image>` 盖上去即可，
地址用 `utils/media.js` 的 `imgUrl()` 拼。

视频按你的要求没有搬 —— 首页开场改成了暖调渐层 + 大爪印水印 + 漂浮贴纸，
保留了网页端"全屏开场 + 双色大标题"的节奏，但不占流量、不卡启动。
