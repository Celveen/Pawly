# 🐾 Pawly 宝狸 · 微信小程序端

**[Pawly](https://github.com/Celveen/Pawly) 的小程序端**，与网页端共用一套 `/api` 接口、
一套设计语言（暖调编辑风），但布局按移动端重排 —— 不是把网页竖着压扁。

## 这版做了什么

| 模块 | 页面 |
|---|---|
| **首页** | 暖调开场（双色大标题 + AI 对话演示卡）· 信任三则 · 编号章节（科普横滑 / 分类宫格 / 人气好物横滑 / 会员卡 / 新到货） |
| **商品** | 搜索 + 分类 + 宠物筛选 + 排序 · 双列商品卡 · 详情（规格 / 简介 / 评价 / 同类）· 购物车 · 结算 · 订单 |
| **宝狸 AI** | tabBar 中间凸起入口 · 流式对话（SSE，自动回落）· 购物方案卡片可一键全加购 · 快捷提问 · 历史 |
| **社区** | 双列瀑布流 · 分区筛选 · 笔记详情（图集 / 点赞 / 收藏 / 评论）· 发笔记（最多 9 图 + 话题标签 + 表情封面） |
| **科普** | 76 篇文章本地内置 · 分类 × 物种双维筛选 · 详情带来源引用、可复制链接、字号切换 |
| **我的** | 资料卡 + 统计 · 每日签到 · 宠物档案 / 健康提醒 / 收货地址 / 订单 · 会员中心 · 私信 · 通知 · 设置 |

## 目录结构

```

config.js                        useMock / baseUrl / 流式开关
api/          request.js         统一请求层（身份走 x-pawly-uid 请求头）
              index.js           接口清单，与网页端 app/api 一一对应
mock/         index.js           拦截 wx.request，无后端也能跑通全站
              seed.js            社区示例内容（与后端 community-seed.ts 同源）
data/         products.js        59 件商品（与 lib/catalog.ts 同源）
              articles.js        76 篇科普（与 components/data.js 同源）
components/                      导航栏 / 商品卡 / 文章卡 / 笔记卡 / 章节标题 / 空状态
custom-tab-bar/                  5 个 tab，中间「宝狸」凸起圆钮
pages/                           主包：首页 / 商品 / 宝狸 AI / 社区 / 我的
packageShop/                     分包：商品详情 / 购物车 / 结算 / 订单
packageContent/                  分包：科普列表 / 科普详情
packageSocial/                   分包：笔记详情 / 发笔记 / 个人主页 / 私信 / 会话 / 通知
packageUser/                     分包：会员 / 宠物档案 / 健康提醒 / 地址 / 登录 / 设置 / 搜索
docs/                            后端对接改动、上线前要做的事
```

## 快速开始

用微信开发者工具「导入项目」选这个目录即可 —— **不需要 `npm install`，也不需要「构建 npm」**。
`config.js` 默认 `useMock: true`，不连后端就能把所有界面点通。

（原模板的 TDesign 组件库已移除：界面全是按 Pawly 视觉手写的，日期/地区用小程序原生 `<picker>`。
想用回来就 `npm i tdesign-miniprogram@1.11.2` 再「工具 → 构建 npm」。）

接真后端、配域名、放 API Key、上线检查清单，见：

- [`docs/后端对接改动.md`](docs/后端对接改动.md) —— 后端要改的三处（两处必改）
- [`docs/上线前要做的事.md`](docs/上线前要做的事.md) —— 域名备案、Key 放哪、审核清单

## 设计说明

设计 token 完全对齐网页端 `app/globals.css`：奶油黄底 `#F7F2E5`、深林绿字 `#1F2A1D`、
赤陶橙点缀 `#DE7429`、全站爪印底纹、发丝线分隔、紧字距大标题。

移动端的重排原则：

- 网页的顶部 pill 导航 → 底部 5 tab + 中间 AI 凸起钮
- 网页的横向多列编辑排版 → 竖向章节 + 横滑卡片轨道
- 网页的浮窗 AI 客服 → 独立的全屏对话页（tab 中间入口）
- 网页的抽屉式购物车 → 独立页面 + 底部固定结算条
- 视频位 → 暖调渐层 + 大爪印水印 + 漂浮贴纸（不占流量、不拖启动）
